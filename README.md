# zammad-max-bot

Max-бот для интеграции с Zammad.

## Описание

Бот предназначен для обработки заявок и взаимодействия с системой Zammad.

## Структура проекта

- `main.py` - основной файл запуска бота
- `config.py` - конфигурация приложения
- `handlers/` - обработчики команд и сообщений
- `models/` - модели данных
- `services/` - бизнес-логика и сервисы
- `utils/` - вспомогательные утилиты
- `database/` - работа с базой данных
- `polling_service.py` - сервис опроса (polling)
- `webhook_server.py` - сервер вебхуков
- `shared_state.py` - общее состояние приложения

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте переменные окружения в `config.py`

## Запуск

### Через Docker

```bash
docker-compose up --build
```

### Локально

```bash
python main.py
```

## Требования

- Python 3.x
- Зависимости указаны в `requirements.txt`
